# Чекліст перед релізом

## Усі продукти
- [ ] CI зелений: Secrets, Code, Dependencies, Infrastructure.
- [ ] Немає винятків без причини й дати перегляду (`.gitleaksignore`, `.semgrepignore`, `osv-scanner.toml`).
- [ ] Секрети prod окремі від dev/staging і лежать у менеджері секретів.
- [ ] Ліміти витрат і алерти на всіх платних API та хмарі.
- [ ] SECURITY-BRIEF.md актуальний.

## Веб / API (середній і високий рівень)
- [ ] DAST (ZAP baseline) проти staging без нових попереджень.
- [ ] `python3 livecheck.py https://staging...` (vibe-audit): заголовки, cookies, `.env`/`.git` не віддаються.
- [ ] Rate limit на логін, реєстрацію, скидання пароля, відправку кодів.
- [ ] Бази даних і адмінки не доступні з інтернету.

## Mac / мобільні
- [ ] Підпис коду, нотаризація (macOS), Hardened Runtime.
- [ ] Секрети користувача — лише Keychain/Keystore. Жодних API-ключів сервісів у бінарнику.
- [ ] Мінімальні entitlements і дозволи, ATS без винятків.
- [ ] Оновлення підписані (Sparkle EdDSA або App Store).

## ШІ / боти
- [ ] Кожен виклик LLM за авторизацією, з `max_tokens` і rate limit.
- [ ] Небезпечні дії агента вимагають підтвердження людини.
- [ ] Боти: токен у секретах, білий список адмінів, секрет вебхука.
- [ ] Ключі бірж/брокерів без права виводу, з білим списком IP, аварійна зупинка працює.

## Високий рівень ризику (додатково)
- [ ] Ручне рев'ю змін в авторизації, платежах, роботі з ключами.
- [ ] `/security-review` у Claude Code на диф релізу, знахідки закриті.
- [ ] План інциденту (INCIDENT.md) актуальний, контакти заповнені.
