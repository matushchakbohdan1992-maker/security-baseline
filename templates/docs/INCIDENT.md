# План реагування на інцидент

Роздрукуйте або збережіть офлайн: під час інциденту може не бути доступу до звичних інструментів.

## Ознаки інциденту
- Знайдено ключ, токен або пароль у коді, логах, чаті, публічному місці.
- Різкий ріст витрат на API, хмару, SMS.
- Невідомі входи, сесії, OAuth-застосунки, SSH-ключі, deploy-ключі.
- Невідомі коміти, релізи, репозиторії (наприклад, `tpcp-docs`), зміни workflow.
- Повідомлення від користувача, партнера, GitHub, провайдера про підозрілу активність.
- Операції на біржі/рахунку, яких ви не робили.

## 1. Зупинити (перші 15 хвилин)
- [ ] Відкликати (revoke) скомпрометований ключ/токен **до** створення нового.
- [ ] Для грошових сервісів: заморозити торгівлю/виплати, вимкнути API-ключі.
- [ ] Вимкнути вразливу функцію, ендпоінт або весь сервіс, якщо інакше не можна.
- [ ] Змінити пароль і завершити всі сесії в зачепленому акаунті, перевірити 2FA.

## 2. Оцінити (першу годину)
- [ ] Що саме скомпрометовано: який ключ, які дані, які системи.
- [ ] З якого часу: перший коміт із секретом, перша підозріла дія в логах.
- [ ] Кого зачіпає: користувачі, партнери, гроші.
- [ ] Зберегти докази: логи, скріншоти, ID транзакцій (до очищення).

## 3. Виправити
- [ ] Закрити причину (код, конфіг, доступ).
- [ ] Перевипустити **всі** секрети, які були доступні в тому ж місці (той самий `.env`, той самий CI).
- [ ] Почистити історію git від секрету (`git filter-repo`) — після перевипуску, не замість.
- [ ] Перевірити, що зловмисник не залишив доступ: OAuth-застосунки, SSH/deploy-ключі, вебхуки, нові адміни, правила пересилання пошти.

## 4. Повідомити
- [ ] Користувачів і партнерів, якщо зачеплені їхні дані або гроші.
- [ ] Провайдера сервісу (біржа, хмара, платіжна система) — вони можуть допомогти заблокувати й повернути.
- [ ] Регулятора/юриста, якщо витекли персональні дані (вимоги залежать від країни).

## 5. Розібрати (протягом тижня)
Коротка нотатка: що сталося → чому → що змінили → яка перевірка тепер це ловить.
Додати перевірку в security-baseline, щоб це не повторилося в жодному продукті.
